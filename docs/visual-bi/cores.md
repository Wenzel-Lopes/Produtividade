# Cores verificadas no PBIX

As cores abaixo foram conferidas nas propriedades dos visuais do arquivo Produtividade.pbix fornecido. As associações consideram o campo usado no visual; o arquivo também contém formatações antigas para outros campos, que não devem ser tratadas como uma paleta global.

| Uso | Cor |
|---|---|
| Lateral e títulos | `#2A6484` |
| Visão diária: colunas padrão | `#33639B` |
| Visão diária: linha de performance | `#FBA324` |
| Classificação: produtivo | `#29AE3F` |
| Classificação: neutro | `#FBA324` |
| Classificação: improdutivo | `#EB1E2D` |
| Mapeamento geral: com sucesso | `#29AE3F` |
| Mapeamento geral: sem sucesso | `#EB1E2D` |
| Detalhe de mapeamento: mapeado | `#94BCC4` |
| Detalhe de mapeamento: não mapeado | `#FBA324` |
| Detalhe de mapeamento: máquina pessoal | `#2A6484` |
| Detalhe de mapeamento: sem máquina | `#757E8B` |
| Formatação por faixa: verde / intermediária / atenção / crítica | `#29AE3F` / `#3C9394` / `#E77517` / `#EB1E2D` |

A prévia utiliza essas cores nos respectivos gráficos. A composição das séries continua ilustrativa; não executa o motor Power BI nem as medidas originais. Cores condicionais dependentes de DAX não foram validadas no Desktop.
