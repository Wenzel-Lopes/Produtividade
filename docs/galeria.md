# Galeria do case Produtividade

**Prévias reconstruídas com dados sintéticos.** Estas imagens foram desenhadas para explicar as frentes do portfólio. Não são screenshots do Power BI original nem comprovam equivalência visual ou funcional com ele.

## Analytics operacional

![Analytics operacional](imagens/analytics.png)

O percurso começa por população e custos, passa pela cobertura e termina na interpretação da atividade observada. [Entenda a análise](analytics.md).

## Controle de mapeamento

![Mapeamento](imagens/mapeamento.png)

O painel diferencia elegíveis, mapeados e lacunas. A série e os recortes por área utilizam o mesmo arquivo de indicadores do backend. [Entenda as regras](mapeamento.md).

## Quer usar filtros?

Baixe o repositório em **Code → Download ZIP**, extraia e abra `site/index.html`. A demonstração HTML oferece filtros de mês e área; o README do GitHub exibe imagens estáticas. Não há link público do Power BI ativo nesta versão.

## Proveniência

Fonte numérica: `reports/metrics.json`, seed 42, janeiro a junho de 2025. A galeria é gerada pelo script `scripts/gerar_galeria.py`, com a biblioteca Pillow. Não usa imagens, identidades ou registros corporativos.
